# Tools

Code generation helpers. The files, that are updated are configured in the central config.md file. The integrity of the single-source-of-truth principle is done by calling test_integrity.py. 

## Utils

The utilities are helper functions used by the scripts in this main folder. The utils search for files, check if an update is really needed, warn if an autogenerated .py file was changed instead of the source of truth for that file. 


## Code Generators

These tools are used for generating code in the main src tree.

### update_sqlalchems.py

Update the SQLAlchemy class files from the puml database description.
